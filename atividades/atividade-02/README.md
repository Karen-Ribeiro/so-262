# Atividade-02

Programa Produtor-Consumidor em Java com buffer limitado (bounded buffer), usando threads.

Aluno: Karen Menezes Ribeiro

## Como rodar

No terminal, dentro da pasta:

```bash
javac *.java
java Factory
```

`Factory` cria o buffer e as threads produtor e consumidor, que ficam rodando em loop produzindo e consumindo itens.
